What is big-release?

big-release is a unified release tool that automates three things for any project:

  1. Version calculation — determines the next version based on your commit history
  2. Changelog generation — creates a human-readable changelog from commits
  3. Package publishing — publishes to npm, PyPI, crates.io, or Go Proxy

Why not just use semantic-release? semantic-release is excellent but only supports Node.js. big-release brings the same workflow to Go, Python, Rust, and any ecosystem with a package registry.

How it works

big-release reads your git history, analyzes commit messages following the Conventional Commits specification, and calculates the next version using Semantic Versioning.

$ big-release

$ big-release --verbose
{"level":"info","msg":"Analyzing commits..."}
{"level":"info","msg":"The next release version is 1.2.0"}
{"level":"info","msg":"Generating changelog..."}
{"level":"info","msg":"Publishing to npm..."}
{"level":"info","msg":"Released 1.2.0"}

Quick setup

Install big-release:

go install github.com/danielvm-git/big-release/cmd/big-release@latest

Create a configuration file:

# .big-release.yml
branches:
  - name: main
tagFormat: "v${version}"
plugins:
  - changelog
  - git
publishers:
  npm:
    enabled: true

Add a release script to your package.json:

{
  "scripts": {
    "release": "big-release"
  }
}
