Greenfield Setup

Starting a new project with big-release is straightforward. This lesson walks through setting up a brand new npm package.

Step 1: Initialize your project

# Create project directory
mkdir my-package && cd my-package
git init

# Initialize npm
npm init -y

# Edit package.json with your package details

Step 2: Configure big-release

Create .big-release.yml at the project root:

# .big-release.yml
branches:
  - name: main
tagFormat: "v${version}"
initialVersion: "0.1.0"
plugins:
  - changelog
  - git
publishers:
  npm:
    enabled: true

Key settings:

  • initialVersion: "0.1.0" — first release starts at 0.1.0
  • tagFormat: "v${version}" — creates tags like v0.1.0
  • publishers.npm.enabled: true — publish to npm

Step 3: Add release script

{
  "scripts": {
    "release": "big-release"
  }
}

Step 4: Create your first commit

# Add files
git add .

# First commit (docs type — no release)
git commit -m "docs: initial commit"

# Second commit (feat type — triggers release)
git commit -m "feat: add greeting function"

Step 5: Test with dry-run

big-release --dry-run

Complete example

Here is a complete walkthrough from zero to first release:

# 1. Setup
mkdir my-package && cd my-package
git init
npm init -y

# 2. Configure
cat > .big-release.yml << EOF
branches:
  - name: main
tagFormat: "v${version}"
initialVersion: "0.1.0"
plugins:
  - changelog
  - git
publishers:
  npm:
    enabled: true
EOF

# 3. Add script to package.json
# "release": "big-release"

# 4. Commit
git add .
git commit -m "docs: initial commit"

# 5. Add feature
cat > index.js << EOF
function greet(name) {
  return `Hello, ${name}!`;
}
module.exports = { greet };
EOF

git add .
git commit -m "feat: add greeting function"

# 6. Test
big-release --dry-run

# 7. Release
big-release
