What it automates

Three things, on every commit

Version calculation

Determines the next version from your commit history using Conventional Commits and SemVer — no manual bumping.

Changelog generation

Creates a human-readable changelog straight from your commit messages, grouped by type.

Package publishing

Publishes to npm, PyPI, crates.io, or Go Proxy — enable one or all of them from a single config.

Works with npm PyPI crates.io Go Proxy
Quick start

Four steps to your first release

1
Install
go install github.com/danielvm-git/big-release/cmd/big-release@latest
2
Configure
# .big-release.yml
branches:
  - name: main
tagFormat: "v${version}"
publishers:
  npm:
    enabled: true
3
Add a release script
{
  "scripts": { "release": "big-release" }
}
4
Release
$ big-release
{"level":"info","msg":"Released 0.1.0"}
